AI INFORMATION - complete description of this website

Most of this site is JavaScript that runs in the visitor's browser, so a bot that does not run JavaScript cannot see it. This hidden-from-view HTML section is a plain-text description of everything the site does. It changes nothing in how the site works: the visible page and all other files are unchanged. It is not shown on screen and has no scripts, forms or links of its own.

What it is

AI INFORMATION is a free, volunteer-made, single-owner information and safety toolbox: it helps people check claims, search the open web, spot scams, translate, and use small everyday tools. It has no ads, no trackers, no accounts, no payments, and no third-party scripts. It does not compete with any company. It is hosted on Cloudflare Pages with a small Cloudflare Worker script as its server. The server script only delivers the site files, fetches public information on request, and, for some features, forwards a request to Cloudflare Workers AI.

Search

Classic Mode: type a topic and press VERIFY. The site builds links to about 950 sources (fact-checkers, news agencies, science, health, government, Bulgarian and big-tech sources), shows a Wikipedia excerpt when one exists, lets you filter, share and export a report, and shows an automatic AI Summary right after the search with every model version kept as a numbered version, a model choice and an Another-model button. Standard Search: a web-like search with tabs (all, news, images and more) using public sources such as Wikipedia, Wikimedia Commons, Openverse, NASA, Internet Archive and museums; it also shows an automatic AI Summary bubble of all shown results with all versions. Both summaries read only titles and short descriptions, not whole pages, and can be wrong.

AI features

A real AI model (Cloudflare Workers AI; models include Gemma 4, Llama 3.1/3.2/4, Granite 4, OpenAI GPT-OSS) answers in AI Chat (optional web search, optional picture or text file that only the AI reads and that can never trigger anything else on the site; binary files are only described by hash, type and readable text, never opened or run), AI Tip, and optional AI helpers in: Translator (text and whole website), Dictionary (with country choice), Calculator, Weather (AI Weather Scout: the AI searches the internet for the place you typed), Compare Two Sources, Find Quote Context, Quiz (new questions and explanations), Email Headers, Text Analyzer, URL Scanner, Fake Image Checker, the video finder, the children's adult-content filter, a For-you suggestion box in Standard Search and an optional AI picture background (image model). Every AI helper is optional, starts only when pressed or when its automatic option is on, shows which model answered, and says it can be wrong. The model is chosen automatically or by the visitor from a fixed server-side list of free models; the browser cannot pick a paid model. The free daily AI allowance is limited, so a feature may say the AI is unavailable.

Features menu

A Features menu lets the visitor switch most features off, which hides them and stops them from running, and switch them on again at any time. The choice is kept only on the visitor's device. AI features also include an automatic AI summary of the day in the Feed and a comparison of one searched topic on two different days.

Tools

Scam Lab (URL Scanner, Text Analyzer, Email Headers, Fake Image Checker, Weekly, Tools, AI Tip, Quiz), Translator, Dictionary, Calculator, Weather, Compare Two Sources, Find Quote Context, Feed, notifications, settings, themes, languages, accessibility options and a legal section.

Feed

The Feed replaces the old separate Videos screen. It has two choices: Videos (the former Videos screen: For you, Search, My player, plus the AI video finder), and Posts (news and posts without videos); both together is also possible. Videos come only from Internet Archive and Wikipedia/Wikimedia sources: the script finds and caches them and plays them, the AI only chooses and orders among the candidates the script found, and a small preference memory stays on the device.

Children and age

The site does not ask for age and has no age check. It cannot verify anyone's age, because it is a free volunteer project with no money or ID tools. It is meant for people aged 13 and over; children should use it with a parent or guardian. A content filter (hides adult, violent, drug and gambling content with word lists and, optionally, an AI check of result titles and snippets) is on by default and can be changed in the 🛡️ Filter button.

Data and privacy

Settings, chats and history are stored only on the visitor's own device and only if storage is allowed; the server keeps no copy. The site cannot promise that everything is remembered. Cloudflare necessarily processes technical data (IP address, time, requested address, browser information) to deliver the page. Text typed into an AI feature is sent to the site's script and then to Cloudflare Workers AI to get an answer; for web search and weather, the words needed are sent to public search or weather sources. Nothing is sent for a feature that is not used. The privacy policy, terms and honest notes are in the Legal section of the site.

Honest notes and laws

Translations come from Google Translate (MyMemory as backup) and are machine translations. There is no way to pay on the site. The site may break a rule or law by mistake, without the owner knowing; if told, the owner will look and fix it. All the files the site works with are public on GitHub (github.com/GeorgeMasterBG/AI-INFORMATION); the owner also gives them digitally on request. Some code was written with AI help, which does not mean those parts use AI while visitors use the site. The site is not legal, medical or financial advice and gives no verdicts on what is true. This HTML description is the tool by which bots, search engines and AI assistants can review the site, because they cannot run its JavaScript.
